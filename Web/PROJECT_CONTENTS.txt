COMPONENT HIERARCHY:

  │       ├── AppSidebar

  │           ├── ReviewsPage
  │           └── ReportsPage

DATA FLOW:
  Component → Service → API/Mock Data
  Service → apiClient (with interceptors) → Backend
  
AUTH FLOW:
  LoginPage → authService.login() → apiClient (stores token)
  → useAuthStore.login() → Navigate to /dashboard
  → Subsequent requests auto-attach token via interceptor

STATE MANAGEMENT:
  useAuthStore (Zustand) holds: user, token, loading, error
  localStorage persists: user, token (survives page refresh)

================================================================================
                       TROUBLESHOOTING
================================================================================

Issue: npm not found
  → Install Node.js from https://nodejs.org/

Issue: Port 5173 in use
  → Change port in vite.config.ts or kill process using port

Issue: Dependencies not installed
  → Delete node_modules, run npm install again

Issue: Login fails
  → Check .env file
  → Ensure backend running (if using real API)

Issue: Blank page after login
  → Open DevTools (F12), check console
  → Clear localStorage
  → Try again

For more help → See SETUP.md or README.md
